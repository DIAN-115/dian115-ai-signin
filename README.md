# AI 签到助手

多账号 AI 每日签到插件，参考深色看板风格实现：进度环、统计瓦片、签到日历、最近记录、账号卡片、弹窗账号管理与通知设置。

## 功能

- 页面弹窗添加多个 AI 账号，可编辑、删除、停用。
- 账号密码登录 AI，登录态失效时自动重新登录并重试一次签到。
- 默认每天 00:01 对所有启用账号签到，也可全局或单账号手动触发。
- 汇总累计签到、最长连续、本月签到，并按账号聚合最近 5 周签到日历。
- 成功、已签到、失败通知可分别开关。
- 账号密码仅保存在插件私有设置/KV，不写入源码、日志、通知或历史记录。

## 配置

在「添加账号」弹窗填写：

- 账号备注
- 站点地址
- 用户名或邮箱
- 密码（编辑已有账号时留空表示保留原密码）
- 是否启用该账号

## 数据

- `last_result`：最近一次签到结果，按账号 ID 区分。
- `sign-history`：按账号 ID 记录签到历史，用于日历和统计。

## 说明

本插件只调用用户配置的 AI 站点接口，不包含多站点 Cookie、答题、图形/视觉验证码识别或第三方站点预警能力。
